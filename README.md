# resumo-do-lab
Laboratório Azure — DIO

Este repositório contém o registro e o resumo das principais lições aprendidas durante o desenvolvimento do laboratório prático de Microsoft Azure realizado na plataforma DIO (Digital Innovation One).

Durante o laboratório, foram explorados conceitos fundamentais da plataforma Azure, proporcionando uma visão inicial sobre seus principais recursos, serviços e funcionalidades.

Conteúdos e aprendizados

Durante a realização do laboratório, foram abordados os seguintes tópicos:

Criação de uma conta no Microsoft Azure, conhecendo o processo inicial de acesso à plataforma.
Navegação pelo Portal do Azure, adquirindo conhecimentos básicos sobre sua interface e organização.
Alteração do idioma do portal, permitindo personalizar a experiência de utilização da plataforma.
Personalização da aparência, explorando as opções de configuração visual disponíveis no portal.
Visão geral dos principais serviços do Azure, obtendo uma compreensão inicial sobre os recursos oferecidos pela plataforma.
Computação, explorando os recursos relacionados à criação e gerenciamento de máquinas e outros serviços computacionais.
Redes, conhecendo conceitos e recursos relacionados à infraestrutura de rede dentro do Azure.
Azure Bastion, compreendendo sua utilização como uma alternativa segura para acesso às máquinas virtuais sem a necessidade de expor diretamente determinados recursos à internet.
Armazenamento, explorando os principais conceitos e recursos de armazenamento disponíveis na plataforma.
Versões prévias (Preview), entendendo que determinados recursos ainda estão em fase de desenvolvimento ou avaliação e podem não possuir as mesmas garantias de disponibilidade e estabilidade dos recursos em produção.
Considerações finais

O laboratório proporcionou uma introdução prática ao Microsoft Azure, permitindo conhecer a estrutura do portal e explorar diferentes categorias de serviços, principalmente computação, redes e armazenamento.

Também foi possível compreender a importância de avaliar o nível de maturidade dos recursos disponibilizados pela plataforma, especialmente aqueles identificados como Preview, que devem ser utilizados com cautela e, em geral, não são recomendados para ambientes de produção sem uma avaliação adequada.

Este laboratório representa uma etapa inicial no aprendizado sobre computação em nuvem e Microsoft Azure, servindo como base para estudos e experimentações mais avançadas na plataforma
